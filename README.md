# Algorithmique en Java

Travaux étudiants de 2004, conservés comme archives pédagogiques.

Exercices sur les piles, les files, les listes doublement chaînées, les arbres binaires, les anagrammes et la récursivité.

Les dossiers regroupent les énoncés disponibles et différentes implémentations réalisées pendant les travaux pratiques. Le code reflète les outils et pratiques de cette période.

Les propositions d’amélioration sont bienvenues dans les issues et les pull requests.
